## 🎯 **Getting Started**

### **For Developers:**
1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/food-dynasty.git
   cd food-dynasty
   ```

2. **Serve locally:**
   ```bash
   python -m http.server 8000
   # OR
   npx serve .
   ```

3. **Open in browser:**
   ```
   http://localhost:8000
   ```

### **For Restaurant Owners:**
1. **Update restaurant information** in the HTML files
2. **Replace images** in the `img/` folder with your restaurant photos
3. **Modify contact details** throughout the website
4. **Customize menu items** in `menu.html`
5. **Update team information** in `team.html`
